# 000\_ComfyUI\_ABC

ComfyUI 增强节点合集：把「子图节点、图片裁剪、万能滑条、忽略组、图片节点、视频节点」，并附带可开关的界面整理功能（设置页 / 标题徽章 / 端口效果）。

## 设计理念

市面上的增强节点往往各自成包、各写一套前端，装多了互相打架。本插件把常用的几件工具收拢到一个包里，共用一套前端基础设施（设置读写、端口效果、子图机制、快照记录），彼此复用而不是各造轮子。

另一条准则是**能引用官方能力就不自己重写**：子图创建/序列化走官方 `LGraph.createSubgraph` / `Subgraph.asSerialisable`，局部执行走官方 `partial_execution_targets`，预览取址走官方 `/view` 路由。插件只做官方没提供的那一层，所以升级 ComfyUI 时不容易崩。

## 功能特点

- **六个节点一个包**：001–006 依次为子图节点、图片裁剪、万能滑条、忽略组、图片节点、视频节点，统一挂在节点菜单的 `ABC` 分类下。
- **图片 / 视频节点自带子图**：双击节点即进入内部编辑空间，内部搭好的工作流会被展开参与执行，产出直接回灌到节点上预览。
- **一键局部运行**：点节点上的「运行」只跑这一节（上游用临时的供图/供视频节点顶替），不必重算整条大流程。
- **相机快照式记录 / 还原**：把节点当前完整状态（含内部子图、连线、预览、控件值）存成一份 JSON，随时还原；同名记录自动编号，不需要「另存为」。
- **子图节点（001）一站式增强**：端口胶囊、连线编号徽标、图片/视频/音频/文本四类预览、图像/视频滑块对比、@媒体引用富文本编辑器、可拖高文本框、运行按键，全部内置。
- **界面清爽可控**：`ABC设置` 分类里可勾选隐藏顶栏操作栏与左侧导航上的按键，还能把节点徽章从节点底部搬进标题栏。
- **出错不连坐**：六个节点各自独立加载，任何一个模块出问题只少它自己的节点，其余照常可用。

## 节点功能详解

本节按 001 → 006 排列：001 子图节点功能最丰富、放在最前，其余按序号顺延。

### 001\_子图节点（`A001_SubgraphNode`）

一个自带子图的空壳容器，功能最丰富的一枚。**节点自身不预设输入输出插槽**，进去自己搭；「进入子图」入口由 ComfyUI 原生渲染。

后端（`A001_SubgraphNode.py`）：三个接口族中最健壮的一套 —— 存储目录走 `realpath` 归一（避免插件经符号链接部署时全部读写被误判非法）、文件名过滤 Windows 保留设备名与超长名、删除失败不误报 500，磁盘读写全部丢线程池不阻塞 ComfyUI 的事件循环。

前端（`js/A001/`，共 24 个模块）能力如下：

- **子图本体**：子图创建 / 恢复 / 序列化，以及顶部工具栏与画布尺寸调整的接管，保证节点外观稳定。
- **端口胶囊**：把原生槽位「换皮」成贴边圆点 + 悬停展开面板，圆点与连线端点严格对齐（连线仍由官方计算，插件不改线）。
- **控件网格锚点**：为保证官方能测量出槽位布局（否则连线端点必然错位），在节点里保留一个零尺寸锚点控件，让控件网格宿主始终存在。
- **预览框**：按产物字段自动判定类型，支持**图片 / 视频 / 音频 / 文本**四种渲染，走官方 `/view` 路由取址；连接上游素材变化时自动刷新。
- **对比层**：图像与视频共用一套「两层叠加 + 裁剪」的滑块对比，拖动分界线比较「主内容 vs 对比内容」；缩放节点时自动跟随，且不会重建媒体元素（避免视频黑闪一帧）。
- **连接线编号徽标**：在每条媒体连线中点画一个带序号的小圆点，颜色与编辑器里的 `@` 引用配色一致（图片 / 视频 / 音频各一色），一眼看出这条线对应 `@图片1` 还是 `@视频2`。
- **@文本编辑器**：把提升上来的多行文本框换成自研富文本编辑器 —— 支持 `@媒体引用` 芯片（可点选上游媒体）、`#` 对话块、结构化/原文两种视图；粘贴含 `<Picture 1>` 之类的文本会自动还原成芯片；数据存 `properties.a001_prompt_docs`，重启不丢。
- **编辑器候选菜单**：`@` 菜单的候选来自本节点**一跳上游**的媒体节点，按槽位类型判定图片/视频/音频并分别编号，与后端 `<Picture n>` / `<Video n>` / `<Audio n>` 语义一致；仅图片显示真实缩略图，视频与音频用内联图标。
- **撤销防护与历史**：编辑器内 Ctrl+Z 只撤销文字，不再误触「画布撤销」把节点整个撤掉；自建撤销/重做栈，同内容不入栈，且有层数上限。
- **提升控件滑条**：类型为 int/float 且带 min/max、跨度不超过 4096 的提升控件，自动改造成「滑条 + 数值框」的样子，可直接拖、可键盘微调。
- **可变高文本框**：提升的多行文本框支持拖拽右下角改高度（浏览器原生 resize 实现），并且**拖高文本框不会压缩预览框** —— 节点高度按 `chrome + 期望预览高 - 常量差` 的绝对值模型重算，反复触发也不会累加。
- **统一恢复中枢**：所有外观改造（胶囊、端点、文本框高度、预览框高度、收起控件）由**唯一**一个观察器统一补回，节点 DOM 被界面框架重建后同帧恢复，避免「闪一下才回来」和移动节点时控件闪烁。
- **运行按键**：调官方 `/prompt` 做局部执行（只跑到本节点含其上游），运行中显示忙碌态、再点即取消，并有状态回灌与看门狗兜底。
- **记录 / 还原**：同 005/006 的相机快照机制，格式串 `a001_camera_snapshot`，存于 `js/A001/A001_Workflow/`。
- **加载开关（原生子图伪装）**：按节点开启后，保存工作流时会把本节点序列化成「ComfyUI 原生子图」的形态，让 ComfyTV / Custom Stage 之类的工具能像识别自带子图一样完整展开 001 并看到内部所有节点；默认关闭，关闭时保存为普通 001 形态。伪装只发生在「写盘那一刻」，画布上的节点全程还是 001，自定义功能零损失。
- **控件框按键行**：预览框下方一排按键 —— 收起/展开控件、加载开关、记录、还原、运行，样式与 005 保持一致。

### 002\_图片裁剪（`A002_ImageCrop`）

后端（`A002_ImageCrop.py`）：

- **输入**：`image_base64`（base64 图片字符串，多行文本）、`crop_x` / `crop_y`（-4096 \~ 4096）、`crop_width` / `crop_height`（1 \~ 8192）、`aspect_ratio`（比例预设，默认 `free`）、`fill_color`（填充色，默认 `#000000`，支持 `#RGB` / `#RRGGBB` / `r,g,b` 三种写法）。
- **输出**：`图像`（IMAGE）、`遮罩`（MASK）、`宽度`、`高度`。
- **越界处理**：裁剪框超出原图时不会报错，超出部分用填充色补齐，并把遮罩对应位置标成 1（原图区域为 0），方便下游区分「真实像素」与「补出来的边」。
- **空输入兜底**：没有传图时返回一张 2048×2048 的黑色底图，不会中断流程。
- **性能细节**：base64 解码结果按内容摘要做 LRU 缓存（最多 4 条），并额外做「同一张图字符串未变则复用摘要」的短路，拖动裁剪框改参数时几乎不再重复解码。

前端（`js/A002_ImageCrop.js`）：

- 用 DOM 面板替换原生控件，包含按钮面板、预览画布、信息行，节点本体可自由拉高拉宽。
- 预览区支持拖动/缩放裁剪框，尺寸自动钳制在 10 \~ 8192。
- 内置比例预设：自由、1:1、9:21、3:4、7:9、2:3、16:9、9:16、21:9 等，选定后按比例联动宽高。
- 填充色可直接在面板上改，改动实时反映到预览。

### 003\_万能滑条（`UniversalSlider`）

- **输入**：`数值`（浮点，范围 -999999 \~ 999999，步进 0.01，原生滑条样式）+ `输出类型`（下拉：`float` / `int`）。
- **输出**：`输出`（任意类型），按所选类型返回浮点或整数。
- **超宽范围**：滑条两端可达百万级，既能当 0\~1 的精细调节，也能当大范围数值输入。
- **去重**：内置输入指纹，同一个值重复执行时不会反复触发下游。
- 前端用 DOM 滑条替换原生控件，⚙ 按钮展开内嵌设置框（只调「类型」与「参数」，当前值直接沿用滑条本身的值），平时收起，保持节点整洁；节点最小高度很小，可以压成一条细横条。

### 004\_忽略组（`IgnoreGroup`）

一个「一键忽略 / 恢复所在组」的控制节点，忽略逻辑全部在前端完成，后端不做实际处理、也没有数据输出。

**节点上的大按钮**会按当前所处位置自动变成三种形态（文字分两行排版）：

- **不在任何组里**：在「忽略所有 / 取消所有」之间切换（所有含节点的组都被忽略时，才显示「取消所有」）。
- **在「组中组」的子组里**：显示「忽略本组 / 取消忽略」，切换本组（含其下级子组）的忽略状态；不同父组下的子组互斥，同一父组下的兄弟子组互不影响。
- **在顶层组里**：显示「忽略 / 取消」——点「忽略」把其余组一并忽略，点「取消」让本组恢复正常、其他组保持原样。
- 按钮尺寸随节点自由缩放自适应。

**布尔开关端口**（`switch`）：节点同时提供一个标准布尔输入，语义是「开 = 不忽略 / 恢复本组，关 = 忽略本组」，与按钮状态双向联动。官方那个布尔开关控件被收起来、只保留端口，因此这个开关可以连线，也可以提升到外层供别的节点使用。

**其他细节**：

- 可以放进 ComfyUI 原生子图里使用：节点识别兼容子图场景，开关状态与所在子图的宿主联动，开关连线也有对应的渲染处理。
- 打开工作流时会按**实际组状态**重新校正开关值，不采信存档里的旧值，避免出现「按钮是灰的、组却是亮的」这类不一致。
- 组归属带缓存、组状态刷新做了同帧合并，组多节点多时拖动不会卡。

### 005\_图片节点（`A005_ImageNode`）

容器节点，双击进入内部子图自行搭工作流。

- **输入**：`文本`（多行）、`images`（可选图片）；**输出**：`图片01`。子图内部产出的图片通过 `图片01` 输出回节点，并在节点内直接预览。
- **子图机制**：外层预留端口与内部 `inputNode` / `outputNode` 插槽一一对应，连线同步；子图数据随工作流保存（`properties.subgraph_data_json`），内嵌的原生子图定义会按层注册，恢复后不会变成「未知节点」。
- **执行展开**：真正跑图时把子图内部节点展开进执行队列，所以内部搭的东西是真的在算，不是只画个壳。
- **局部运行**：点「运行」只执行到本节点 —— 上游的 005 会被一个临时 `FeedImage` 顶替，直接读上次的预览图传下去，上游不重算；运行中再点一次即取消。
- **记录 / 还原**：直接拿框架原生序列化结果当快照，尺寸、模式、插槽、控件值、子图、预览一并收录；故意不记录外层节点的 ID 与画布坐标，还原时保持当前位置。还原时子图内部全部 ID 会重新生成，因此同一个画布上复制多份 005 也不会互相冲突。只认自家格式 `a005_camera_snapshot`。
- **预览持久化**：预览图存在节点属性里，关掉工作流再打开，画面上次看到什么就还是什么。
- **文本联动**：面板里的多行文本框与 `文本` 输入端口双向绑定，值实时回写后端控件，序列化与端口绑定都不会丢。
- **对比滑块**：节点预览支持「主图 / 对比图」两张切换对比。

内部节点 `005_供图(内部)`（`A005_FeedImage`，`is_dev_only`，不在节点菜单显示）：

- **输入**：`filename`、`subfolder`、`path_type`（`temp` / `output` / `input`）；**输出**：`图片`。
- 按 `folder_paths` 规则定位文件读成 IMAGE 张量，并做了路径穿越校验（解析后的真实路径必须仍在允许目录内），文件不存在时明确报错而不是静默返回空图。

### 006\_视频节点（`A006_VideoNode`）

结构与 005 完全同构，媒体类型换成视频。

- **输入**：`文本`（多行）、`videos`（可选视频）；**输出**：`视频01`。
- 同样支持双击进入子图、执行展开、局部运行（上游用临时 `FeedVideo` 顶替）、对比视频滑块、预览持久化（`properties._a006_preview`）。
- 记录 / 还原的格式串为 `a006_camera_snapshot`，存于 `js/A006/A006_VideoWorkflow/`。
- 内部节点 `006_供视频(内部)`（`A006_FeedVideo`）读取视频文件并输出 VIDEO 数据，同样带路径穿越防护，且不在节点菜单显示。

## 前端公共池

这三块不属于任何单个节点，服务于整个插件与全局界面。

**A000-1 设置页**（`js/A000/A000_SettingsPage.js` + `A000_SettingsStore.py`）

- 在 ComfyUI 设置的 `ABC设置` 分类下提供可勾选清单，勾选即隐藏主界面上的对应按键，分三组：顶栏操作栏按键、左侧导航侧栏按键、模板页面分类。
- 全部勾选状态存在**唯一一个**数据文件 `js/A000/A000-ABCsettings.json`（含清单折叠偏好），页面加载自动读取、勾选后自动保存（带去抖），不需要点保存按钮。
- **无文件即默认全显示**；文件损坏也按默认处理，不会让设置页打不开。
- 后端写入采用「临时文件 + 原子替换」，中途断电不会留下半截文件；读写在独立线程执行，不占用 ComfyUI 的请求循环。
- 从旧版本升级时，会尝试把历史 localStorage 里的隐藏配置迁移进文件。

**A000-2 标题徽章**（`js/A000/A000_TagMove.js`）

- 新版界面下节点徽章（`#节点ID`、生命周期、节点来源）默认躺在节点底部，白占一行高度。本功能把它搬进标题栏右侧，与标题同一行显示，并缩小徽章高度。
- 界面框架重建节点时会自动重新搬运。可在设置页开关。

**A000-3 端口效果**（`js/A000/A000_Port.js`）

- 统一的「端口聚合胶囊」实现：默认收成一枚小圆点，鼠标悬停才展开真实槽位，展开时自动隐藏系统 tooltip。
- 由 002\_图片裁剪、003\_万能滑条等节点共用同一个函数调用，避免每个节点各抄一份。

**A000-4 DOM 样式注入**（`js/A000/A000_DomStyle.js`）

- 统一的「按 id 一次性注入 <style>」工具，供各前端模块共用。
- 以「目标 <style> 是否仍在 DOM 中」作为唯一幂等判据：正常情况下同一样式只注入一次，且在样式被界面框架清掉后会自动补回。

## HTTP 接口一览

插件向 ComfyUI 后端注册了以下路由（本地接口，供自带前端调用）：

| 方法   | 路径                      | 用途                               |
| ---- | ----------------------- | -------------------------------- |
| GET  | `/a000/settings`        | 读取设置文件，无文件或损坏返回 `{exists:false}` |
| POST | `/a000/settings`        | 整体覆盖写入设置文件（原子写）                  |
| POST | `/a001/workflow/save`   | 记录 001 快照，同名自动加数字后缀              |
| GET  | `/a001/workflow/list`   | 列出 001 的记录（按修改时间倒序）              |
| POST | `/a001/workflow/load`   | 读取指定 001 记录                      |
| POST | `/a001/workflow/delete` | 删除 001 记录（Windows 走回收站）          |

## 安装方法

1. 把整个 `000_ComfyUI_ABC` 文件夹放入 `ComfyUI/custom_nodes/` 目录（或在该目录下 `git clone` 本插件）。
2. **无需安装额外依赖**：用到的 `torch` / `numpy` / `Pillow` / `aiohttp` 均为 ComfyUI 自带。
3. 重启 ComfyUI，刷新浏览器页面（建议强制刷新以清掉前端缓存）。
4. 界面功能（DOM 面板、端口胶囊、标题徽章）需要 ComfyUI 的**新版界面（Nodes 2.0）**；002–004 的节点本身在两种界面下都能使用。

## 使用方法

**找节点**：右键画布 → 在节点菜单里找到 `ABC` 分类，001–006 都在这里（内部供图 / 供视频节点默认不显示，只在局部运行时临时创建）。

**用节点**：

| 想做什么        | 操作                                                     |
| ----------- | ------------------------------------------------------ |
| 裁图          | 拉出 `002_图片裁剪`，把图片接进来（或以 base64 文本传入），在面板上拖裁剪框、选比例、改填充色 |
| 输入一个数字      | 拉出 `003_万能滑条`，拖滑条或在设置框里精确输入，选择输出整数还是浮点                 |
| 临时跳过一组节点    | 把 `004_忽略组` 放进那个组里，点一下按钮即忽略，再点一次恢复                     |
| 搭一段可复用的图片流程 | 拉出 `005_图片节点`，双击进入内部搭建；搭好后点「运行」只跑这一段                   |
| 搭一段视频流程     | 同上，用 `006_视频节点`                                        |
| 要更强的容器      | 用 `001_子图节点`：端口胶囊、@媒体引用编辑器、四类预览、滑块对比、记录还原都内置           |

**整理界面**：打开设置（或界面设置的搜索框），进入 `ABC设置` 分类，勾选要隐藏的顶栏/侧栏按键，并可按需开关「标题徽章」。

**记录与还原**：001 / 005 / 006 面板上的「记录」会把当前节点完整状态存成一份快照，「还原」时从列表里挑一份写回（同名记录按 `名字.json`、`名字_2.json` 依次编号，可回溯多个版本）。

## 技术架构

- **节点规范**：全部节点按 ComfyUI V3 规范编写 —— 继承 `io.ComfyNode`、用 `io.Schema` 声明输入输出、`execute()` 返回 `io.NodeOutput`，入口为 `async def comfy_entrypoint()` 返回 `ABCExtension`。
- **双轨注册**：包内同时提供 `NODE_CLASS_MAPPINGS` / `NODE_DISPLAY_NAME_MAPPINGS` 与 V3 扩展入口，任何一条不可用都不影响另一条，兼容不同版本的宿主加载方式。
- **四层启动顺序**（`__init__.py`）：先赋 `WEB_DIRECTORY`，再前置声明映射表，再加载基础设施（`comfy_api` / `typing_extensions` 各自兜底），最后逐个导入业务模块 —— 每个模块独立 `try`，任一模块导入失败不会牵连其余节点，映射表最后清掉占位空值。
- **前端**：`WEB_DIRECTORY = "./js"`。002\_图片裁剪、003\_万能滑条、004\_忽略组与 005/006 的面板走 `addDOMWidget` 挂真实 DOM（并隐藏同名原生控件，值仍实时同步回后端以保证序列化正确）；001\_子图节点因该 API 会触发界面框架重建，改走「定位官方控件行 → 隐藏 textarea → 手工插入自研组件」的路线，完全脱离控件系统。
- **通信**：Python 侧用 `PromptServer.instance.routes` 注册 HTTP 路由，前端用 `api.fetchApi` 调用；执行状态通过 `executed` / `execution_cached` 事件回灌到预览。
- **共享观察器**：面板守卫、端口观察器、编辑器守卫原本是「每个节点各建一个 MutationObserver 盯同一批 DOM」（N 个节点 = N 份回调）；现已收敛为「模块级唯一观察器 + 节点注册表」，单例回调按节点把变更分组分发，未受影响的节点完全不参与。
- **数据落盘**：设置与快照都写在插件自己的 `js/` 子目录里（可通过 `/extensions` 访问，便于人工核对），写入采用原子替换或线程池执行，读取对损坏文件容错。
